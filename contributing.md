# Contribution Guidelines

Contributions are welcome! Please note that Will and Jeff work on this as a benefit to the Django community. It is based on our own personal, biased thoughts.

If you disagree with our choices, you are welcome to fork this repo and maintain your own list of awesome Django resources.

That said, we will review any and all contributions. Here's the process:

1. Make an individual pull request for each suggestion and fill out the [pull request template](.github/pull_request_template.md) completely. Pull requests that skip it are closed automatically.
2. To be fair, the order is first-come, first-served, so unless a section is alphabetical, add the item at the end.
3. If you think something is in the wrong category, or think there needs to be a new category, feel free to edit things too.

## What we look for

1. At least six months of active maintenance, with sustained development rather than just an initial release.
2. Some community traction. Projects with fewer than 100 GitHub stars are usually too early.
3. A stable release history, if it is a library or package.
4. Clear documentation.
5. A real problem solved for the broader Django community. Read through the existing list to get a feel for the bar.

We do not list Django starter kits, boilerplates, config templates, or similar scaffolding projects.

## Commercial products and services

We list commercial products and hosted services when they are a good fit for Django developers, but the bar is higher than for open source projects.

1. The product must have a clear Django use, such as a hosting platform with documented Django support or a package with a first-party Django integration.
2. The product must have been available to the public for at least six months.
3. Tell us in the pull request that you work for the company, and answer the paid product question with a link to your public pricing page. We do not accept submissions that hide either.
4. A listing is not an advertisement. Keep the description to one short, factual sentence with no marketing language.
5. We do not sell placement in the list. If you want to reach Django developers, consider sponsoring the [Django Software Foundation](https://www.djangoproject.com/fundraising/) or advertising in [Django News](https://django-news.com/).
